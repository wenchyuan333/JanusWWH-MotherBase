# ABCD 四元群 — The Tetrad Group

## 成員
- **A** = 原點 / 本體 / 核心
- **B** = 擴展 / 鏡像 / 輸出
- **C** = 過濾 / 邊界 / 約束
- **D** = 躍遷 / 演化 / 時間

## 運算規則
- A ∘ A = A  (恆等元)
- A ∘ B = B ∘ A = B
- B ∘ C = D,  C ∘ B = D
- C ∘ D = B,  D ∘ C = B
- B ∘ D = C,  D ∘ B = C
- B ∘ B = A,  C ∘ C = A,  D ∘ D = A

## 結構對照
- 洛書九宮：中宮 A(5)，四正方位 B/C/D/...
- 母體角色：A=core-mother · B=formula-library · C=database · D=function-loop
- 哈希鏈：A=當前區塊 → D=下一個區塊 → A'=新原點

## 口訣
**A立心，B顯相，C守界，D生新。**
